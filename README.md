# Chaveiro 24 Horas Tatuapé - Landing Page de Alta Conversão

Landing page de resposta direta e socorro emergencial para chaveiro 24 horas no Tatuapé e região (Jardim Anália Franco, Vila Gomes Cardim, Carrão, Mooca, Belém).

🌐 **Site no ar (GitHub Pages):** [https://kpraiei.github.io/prospectchaveiro/](https://kpraiei.github.io/prospectchaveiro/)


## 🚀 Tecnologias Utilizadas
- **Python / Flask** (Servidor Web)
- **Tailwind CSS** (Design responsivo e utilitários modernos)
- **FontAwesome & Google Fonts** (Tipografia técnica comercial)
- **HTML5 Semântico & SEO Local**

## 📦 Como Rodar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/kpraiei/prospectchaveiro.git
cd prospectchaveiro
```

2. Instale as dependências:
```bash
pip install -r requirements.txt
```

3. Inicie o servidor:
```bash
python app.py
```

4. Acesse no navegador:
```
http://localhost:5000
```

> **Nota:** O arquivo `index.html` também pode ser aberto diretamente no navegador sem necessidade de servidor backend.
